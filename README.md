# Ivory Flow

A minimal writing theme for focused prose. Designed for long-form notes, essays, and documentation.

![Preview of Ivory Flow theme](/ivory-flow-screenshot.png)

## Features

- Clean serif body text (Literata) for comfortable reading
- Sans-serif headings (Inter) for clear hierarchy
- Warm off-white background, easy on the eyes

## Installation
1. Download `ivory-flow.css`
2. In Typora, go to Preferences → Appearance → Open Theme Folder
3. Copy the CSS file into that folder
4. Restart Typora and select Ivory Flow from the theme menu
